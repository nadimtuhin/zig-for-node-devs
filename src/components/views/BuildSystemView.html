Appendix 04 • Build Tooling

`build.zig` vs `package.json`

Type-safe build graphs in Zig instead of Makefiles, CMake, or npm scripts.

Feature Node.js / npm Zig
Build Script Language JSON + bash scripts + Webpack / Vite Pure Zig (build.zig)
Dependency Spec package.json build.zig.zon
Storage node_modules/ (hundreds of MBs per project) Global content-addressed cache (~/.cache/zig)
Security npm post-install scripts execute arbitrary shell commands Strict cryptographic SHA-256 hashes, zero post-install hooks
