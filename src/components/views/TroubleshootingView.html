Appendix 10 • Diagnostics & Debugging

Diagnostics & Debugging Playbook

Diagnose compile-time errors, inspect memory leaks, and debug native binaries with LLDB.

1. Detecting Memory Leaks with GPA

In Debug and Test modes, GeneralPurposeAllocator outputs stack traces for any allocation that was not freed prior to program exit.

const std = @import("std");

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer {
        const check = gpa.deinit();
        if (check == .leak) @panic("Memory leak detected!");
    }
}

2. Native Breakpoints with LLDB / GDB

Zig binaries compile with rich DWARF debug information by default in Debug mode. Step through your code directly in terminal:

# Build with debug symbols
zig build

# Launch debugger
lldb ./zig-out/bin/my_app
(lldb) breakpoint set --file main.zig --line 25
(lldb) run
(lldb) frame variable
