Appendix 01 • Metaprogramming Paradigm

Mastering Zig `comptime`

Why Zig eliminates C preprocessor macros, C++ template errors, and JavaScript runtime reflection in favor of ordinary Zig code executed inside the compiler VM.

⚡ What is `comptime`?

In TypeScript, generics are stripped at build time (type erasure), leaving zero trace at runtime. To inspect objects dynamically in Node.js, you must rely on expensive runtime reflection (Object.keys(), Reflect.get(), class-transformer). In C++, template metaprogramming introduces cryptic compiler errors and huge build times.

In Zig, types are first-class values at compile time. You write ordinary Zig functions, loops, and switches. When a parameter or expression is marked comptime, the Zig compiler executes that code during compilation inside its internal virtual machine, generating specialized, zero-overhead machine code.

1. Type Generics without New Syntax

In Zig, a generic data structure is simply a regular function that takes a comptime T: type parameter and returns a type. We can enforce type constraints with @compileError:

generic_point.zig Zig 
const std = @import("std");

pub fn Point(comptime T: type) type {
    // Assert at compile time that T is either an integer or float
    comptime {
        const info = @typeInfo(T);
        if (info != .int and info != .float) {
            @compileError("Point(T) only supports integer or float types!");
        }
    }

    return struct {
        x: T,
        y: T,

        const Self = @This();

        pub fn distance(self: Self) f64 {
            const x_f64: f64 = switch (@typeInfo(T)) {
                .int => @floatFromInt(self.x),
                .float => @floatCast(self.x),
                else => unreachable,
            };
            const y_f64: f64 = switch (@typeInfo(T)) {
                .int => @floatFromInt(self.y),
                .float => @floatCast(self.y),
                else => unreachable,
            };
            return @sqrt(x_f64 * x_f64 + y_f64 * y_f64);
        }
    };
}

pub fn main() void {
    const PointI32 = Point(i32);
    const pt1 = PointI32{ .x = 3, .y = 4 };
    std.debug.print("Distance: {d}\n", .{pt1.distance()}); // 5.0

    const PointF32 = Point(f32);
    const pt2 = PointF32{ .x = 1.5, .y = 2.0 };
    std.debug.print("Distance: {d}\n", .{pt2.distance()}); // 2.5
}

2. Comptime Reflection with `@typeInfo` and `inline for`

Notice inline for! A regular for loop executes at runtime. An inline for loop executes at compile time, unrolling the iteration completely. This allows writing zero-allocation serializers without runtime reflection overhead:

serializer.zig (Zero-Overhead Reflection) Zig 
const std = @import("std");

pub fn printStructFields(comptime T: type, value: T) void {
    const info = @typeInfo(T);
    switch (info) {
        .@"struct" => |s| {
            std.debug.print("Inspecting struct {s}:\n", .{@typeName(T)});
            inline for (s.fields) |field| {
                const val = @field(value, field.name);
                std.debug.print("  - {s} ({s}) = {any}\n", .{
                    field.name,
                    @typeName(field.type),
                    val,
                });
            }
        },
        else => @compileError("printStructFields requires a struct type!"),
    }
}

const UserAccount = struct {
    id: u64,
    name: []const u8,
    active: bool,
};

pub fn main() void {
    const user = UserAccount{ .id = 42, .name = "Alice", .active = true };
    printStructFields(UserAccount, user);
}

3. Compile-Time String Hashing for Fast Dispatch

Instead of executing linear string comparisons (`std.mem.eql`) across hundreds of API routes at runtime, you can compute 64-bit FNV-1a hashes at compile time and switch on integer cases:

comptime_router.zig Zig 
const std = @import("std");

pub fn hashString(s: []const u8) u64 {
    var h: u64 = 0xcbf29ce484222325;
    for (s) |b| {
        h = (h ^ b) *% 0x100000001b3;
    }
    return h;
}

pub fn route(path: []const u8) []const u8 {
    // When called in a switch pragma, hashString is evaluated at compile time!
    switch (hashString(path)) {
        comptime hashString("/health") => return "200 OK: Healthy",
        comptime hashString("/api/v1/users") => return "200 OK: Users List",
        comptime hashString("/api/v1/orders") => return "200 OK: Orders List",
        else => return "404 Not Found",
    }
}

pub fn main() void {
    std.debug.print("Route result: {s}\n", .{route("/health")});
}

TypeScript vs Zig Metaprogramming

Feature TypeScript Zig
Generics Erased at runtime; no runtime verification Generates dedicated concrete machine code per type
Dynamic Reflection Reflect.get, Object.keys() (slow heap lookups) @typeInfo() and inline for (zero runtime cost)
Compile Validation Static types only; cannot execute code at build Full compiler VM with @compileError()
