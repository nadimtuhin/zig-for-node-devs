Appendix 03 • Native Integration

C Interop & Node-API Addons

Replacing node-gyp, Python scripts, and complex C++ binding glue with pure Zig.

🔌 Zig is a Full C Compiler

Zig ships with Clang built directly into its binary. You do not need GCC, CMake, or Make installed on your system. You can include C header files directly in your Zig source code using @cImport.

Building a Native Node.js Addon in Zig

// addon.zig
const std = @import("std");

// Export C ABI symbols
export fn add(a: i32, b: i32) i32 {
    return a + b;
}

export fn fastMultiply(a: f64, b: f64) f64 {
    return a * b;
}

Compile to a shared dynamic library with one terminal command:

zig build-lib addon.zig -dynamic -O ReleaseFast

Call it from Node.js using node:ffi-napi or process.dlopen:

import ffi from 'ffi-napi';

const lib = ffi.Library('./libaddon.dylib', {
  'add': ['int', ['int', 'int']],
  'fastMultiply': ['double', ['double', 'double']]
});

console.log(lib.add(40, 2)); // 42
