Appendix 07 • Classic Algorithms

LeetCode in Idiomatic Zig

Classic algorithmic patterns solved with explicit allocators, fixed stack buffers, and in-place slice operations.

Direct Answer

Classic LeetCode problems translate to Zig with three habits: hash tables come from std.AutoHashMap(K, V).init(allocator) and need defer map.deinit(), bounded stacks can live in a fixed array like [256]u8 with no heap use, and linked lists are walked through optional pointers (?*Node) with while (current) |curr|. Zig has no garbage collector, so allocation happens only where you call an allocator. Run any snippet with zig test file.zig.

1. Two Sum — O(N) Hash Table Lookup

In Node.js you reach for new Map() and the garbage collector owns it. Zig's AutoHashMap is an open-addressing hash table stored in contiguous arrays, and you own it: it takes an allocator and must be released with deinit(). Time O(n), space O(n). Note that target - num panics on overflow in Debug and ReleaseSafe builds.

const std = @import("std");

fn twoSum(allocator: std.mem.Allocator, nums: []const i32, target: i32) !?[2]usize {
    var map = std.AutoHashMap(i32, usize).init(allocator);
    defer map.deinit();

    for (nums, 0..) |num, idx| {
        const complement = target - num;
        if (map.get(complement)) |prev_idx| {
            return .{ prev_idx, idx };
        }
        try map.put(num, idx);
    }
    return null;
}

2. Valid Parentheses — Fixed-Size Stack, No Heap

Instead of a dynamic array, this uses a pre-sized stack buffer and a single pass over the bytes. Time O(n), space O(1) because the buffer size is constant. Trade-off: input nested deeper than 256 levels returns false even if it is balanced, so switch to std.ArrayList(u8) when depth is unbounded.

fn isValid(s: []const u8) bool {
    var stack: [256]u8 = undefined;
    var top: usize = 0;

    for (s) |char| {
        switch (char) {
            '(', '{', '[' => {
                if (top >= stack.len) return false;
                stack[top] = char;
                top += 1;
            },
            ')' => { if (top == 0 or stack[top - 1] != '(') return false; top -= 1; },
            '}' => { if (top == 0 or stack[top - 1] != '{') return false; top -= 1; },
            ']' => { if (top == 0 or stack[top - 1] != '[') return false; top -= 1; },
            else => {},
        }
    }
    return top == 0;
}

3. Reverse Linked List — In-Place Pointer Manipulation

In JavaScript this is the same pointer rewiring on object references, with V8 reclaiming nodes later. In Zig the reversal itself allocates nothing: it rewires next pointers in place, and whoever created the nodes decides when to free them. Time O(n), space O(1).

const Node = struct {
    val: i32,
    next: ?*Node = null,
};

fn reverseList(head: ?*Node) ?*Node {
    var prev: ?*Node = null;
    var current = head;

    while (current) |curr| {
        const next_node = curr.next;
        curr.next = prev;
        prev = curr;
        current = next_node;
    }
    return prev;
}

4. Binary Search — Overflow-Safe Midpoint

JavaScript uses Math.floor((left + right) / 2) on floating-point numbers. Zig uses fixed-width integers, so left + (right - left) / 2 avoids overflowing left + right on very large slices, and integer division already truncates. Time O(log n), space O(1).

fn binarySearch(nums: []const i32, target: i32) ?usize {
    if (nums.len == 0) return null;
    var left: usize = 0;
    var right: usize = nums.len;

    while (left < right) {
        const mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    return null;
}

How Do I Test These Solutions in Zig?

Zig has built-in test blocks. Put them in the same file as the solutions and run zig test leetcode.zig. Passing std.testing.allocator to twoSum also proves the hash map was freed.

test "twoSum finds the pair" {
    const nums = [_]i32{ 2, 7, 11, 15 };
    const result = try twoSum(std.testing.allocator, &nums, 9);
    try std.testing.expectEqual([2]usize{ 0, 1 }, result.?);
}

test "isValid" {
    try std.testing.expect(isValid("([]{})"));
    try std.testing.expect(!isValid("(]"));
}
