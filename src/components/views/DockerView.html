Appendix 06 • Container Architecture

Production Docker Recipes (< 5MB Scratch)

Zero-vulnerability deployment: How statically-linked Zig binaries eliminate 300MB of Linux runtime bloat and eliminate CVE alerts.

Production Multi-Stage Dockerfile (Static Scratch Build) 
# Stage 1: Build the static Zig binary
FROM alpine:3.20 AS builder

# Install Zig compiler
RUN apk add --no-cache zig

WORKDIR /build
COPY . .

# Statically compile with Musl libc target and ReleaseSmall optimization
RUN zig build -Doptimize=ReleaseSmall -Dtarget=x86_64-linux-musl

# Stage 2: Pristine zero-dependency Scratch container
FROM scratch

# Copy the standalone compiled binary
COPY --from=builder /build/zig-out/bin/server /app

# Optional: Copy SSL CA certificates if making outbound HTTPS requests
# COPY --from=builder /etc/ssl/certs/ca-certificates.crt /etc/ssl/certs/

EXPOSE 8080
USER 10001:10001

ENTRYPOINT ["/app"]
