Appendix 02 • Systems Memory

The Allocator Architecture

No hidden malloc, no stop-the-world V8 GC pauses, and zero mysterious memory leaks.

🟢 Node.js V8 Model

Every new Object() or string allocates memory silently on the V8 heap. Garbage collection runs periodically, interrupting CPU execution to sweep dead objects.

🦎 Zig Explicit Allocator Model

NO function can allocate heap memory without being handed an explicit allocator: std.mem.Allocator. You choose the exact memory strategy (GPA, Arena, FixedBuffer).

The Big Three Allocators in Zig

Allocator Best Used For Cleanup Behavior
GeneralPurposeAllocator (GPA) Application-wide root allocator. Catches double-free and memory leaks in debug mode. Individual allocator.free(slice)
ArenaAllocator HTTP request lifecycles, CLI commands, parsing passes. Batch free via arena.deinit() in one single call.
FixedBufferAllocator Stack buffers, zero OS syscalls, real-time audio, embedded systems. Zero OS freeing; automatically reclaimed on stack frame exit.
