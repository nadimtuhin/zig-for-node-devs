Appendix 02 • Systems Memory

The Allocator Architecture

No hidden malloc, no stop-the-world V8 garbage collection pauses, and zero mysterious memory leaks through explicit allocator passing.

Node.js / V8

Automatic Garbage Collection

Every object, closure, or string is allocated on the V8 heap. Generational garbage collection (Scavenge + Mark-Sweep-Compact) runs periodically, causing unpredictable tail latencies and multi-gigabyte memory bloat.

Zig Systems Model

Explicit Allocator Injection

No function in the Zig standard library can allocate heap memory without being passed an explicit allocator: std.mem.Allocator. If a function does not accept an allocator, it is mathematically guaranteed not to allocate heap memory.

🔍 What is `std.mem.Allocator`?

In Zig, an allocator is not a heavyweight C++ virtual class or an invisible runtime global. It is a 16-byte fat pointer consisting of two words:

pub const Allocator = struct {
    ptr: *anyopaque,
    vtable: *const VTable,
    // VTable functions: alloc, resize, free
};

1. GeneralPurposeAllocator (GPA): Leak & UAF Detection

Use GPA as the top-level application root allocator. In Debug and ReleaseSafe modes, it tracks every active allocation and prints stack traces if any memory is leaked upon exit:

gpa_example.zig Zig 
const std = @import("std");

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer {
        const deinit_status = gpa.deinit();
        if (deinit_status == .leak) {
            std.debug.print("❌ Memory leak detected by GPA!\n", .{});
        }
    }
    const allocator = gpa.allocator();

    // Allocate dynamic slice
    const numbers = try allocator.alloc(i32, 5);
    defer allocator.free(numbers); // Pair allocation with defer free!

    for (numbers, 0..) |*val, idx| {
        val.* = @intCast(idx * 10);
    }
    std.debug.print("Allocated: {any}\n", .{numbers});
}

2. ArenaAllocator: Batch Free for HTTP & CLI Lifecycles

The ArenaAllocator wraps any child allocator. Individual allocations do not need individual free() calls. Calling arena.deinit() instantly reclaims the entire pool in a single pointer reset:

arena_example.zig Zig 
const std = @import("std");

fn handleRequest(root_allocator: std.mem.Allocator) !void {
    var arena = std.heap.ArenaAllocator.init(root_allocator);
    defer arena.deinit(); // Instant batch cleanup for all 10,000 allocations!
    const req_allocator = arena.allocator();

    var list = std.ArrayList([]const u8).init(req_allocator);
    var i: usize = 0;
    while (i < 100) : (i += 1) {
        const item = try std.fmt.allocPrint(req_allocator, "User session #{d}", .{i});
        try list.append(item);
    }

    std.debug.print("Processed {d} items with zero individual frees!\n", .{list.items.len});
}

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer _ = gpa.deinit();
    try handleRequest(gpa.allocator());
}

3. FixedBufferAllocator (FBA): Zero-Syscall Stack Execution

When building embedded systems, kernel drivers, or high-frequency trading engines, OS syscalls (`mmap`/`brk`) are unacceptable. FBA turns any pre-allocated stack buffer into a memory allocator:

fixed_buffer_example.zig Zig 
const std = @import("std");

pub fn main() !void {
    // 64 KB allocated strictly on the CPU stack
    var stack_buffer: [64 * 1024]u8 = undefined;
    var fba = std.heap.FixedBufferAllocator.init(&stack_buffer);
    const allocator = fba.allocator();

    // Allocates inside stack_buffer with ZERO OS syscalls
    const text = try std.fmt.allocPrint(allocator, "Ultra-fast stack formatted string: {d}", .{42});
    std.debug.print("{s}\n", .{text});
}

📊 Allocator Strategy Decision Guide

Scenario Recommended Allocator Primary Benefit
Main Application Root std.heap.GeneralPurposeAllocator Debug leak detection, bounds protection
HTTP Request / CLI Command std.heap.ArenaAllocator Instant batch deallocation, zero leak risk
Real-time Audio / HFT / Embedded std.heap.FixedBufferAllocator Zero OS syscalls, deterministic performance
Unit & Integration Tests std.testing.allocator Fails test automatically on any leaked byte
